<h1 align="center">紫孔雀插件</h1>

基于 AstrBot 的紫孔雀挂机脚本状态查询插件：设备定时上报状态，QQ 里随时查看脚本运行情况、拉取日志、截图（查询类**只读**）；另支持扫码提取存档（操控脚本，仅私聊）。

> **⚠️ Beta 版本**：当前为公开测试版，可能存在不稳定因素，欢迎 [Issue](https://github.com/zhangkuo/astrbot_plugin_zkq/issues) 反馈问题。

## 功能特性

- **设备状态查询**：当前账号、运行模式、下次升级倒计时、最近事件、在线状态
- **服务器状态查询**：CPU / 内存 / 磁盘 / 开机时长 / AstrBot 运行时长
- **日志**：按行/按小时/按天查看（AI 总结或原文），完整日志打包 zip 发送
- **截图**：设备实时截图，PNG 原图打包发送（QQ 文件传输不失真）
- **AI 对话**：直接在聊天里问"设备在干什么""服务器状态怎么样""截个图看看"，AI 自动调用工具
- **设备重名自动处理**：改备注即清理旧名；重名冲突自动加 `-2`、`-3`
- **安全只读**：设备只出站连接（无需端口映射/隧道）；查询类命令不修改脚本状态，扫码提取/清空日志为破坏性操作（仅私聊）

## 安装

1. 把 `astrbot_plugin_zkq` 文件夹放入 AstrBot 的 `data/plugins/` 目录
2. 控制台 → 插件 → 重新加载（或重启 AstrBot）
3. 插件配置面板中打开「启用问答」总开关

## 配置说明

| 配置项 | 说明 |
|---|---|
| 启用问答 | 总开关，关闭后设备无法连接 |
| 设备通讯端口 | 设备与服务器通讯端口（默认 16841，需防火墙放行） |
| 共享密钥 | 与 App 里填的一致，留空不校验 |
| QQ 白名单 | 群聊允许查询的 QQ（多个用逗号隔开，留空不限制；私聊始终放行） |
| 设备上报间隔 | 设备状态上报间隔（秒） |
| 日志保留天数 | 统一控制所有设备的日志保留天数，超过自动删除 |
| 日志显示行数 | 文本查看时显示的日志行数 |
| 单条回复字数上限 | 单条回复字数上限 |

## 使用方式

### 前缀命令

```
/zkq 设备列表         查看所有设备（在线状态）
/zkq 状态 <设备>      设备状态快照
/zkq 全部             所有设备汇总
/zkq 服务器           服务器状态（CPU/内存/磁盘）
/zkq 日志 <设备>      最近日志（文本）
/zkq 日志文件 <设备>  完整日志打包 zip 发送
/zkq 错误 <设备>      error.log 尾部
/zkq 截图 <设备>      设备实时截图（zip 原图）
/zkq ping <设备>      链路测试
/zkq 清空日志 <设备>  删除日志（仅私聊）
/zkq 重置token        重置设备通讯密钥（仅私聊）
/zkq 扫码提取 <设备> <槽位> [QQ|微信]   远程扫码链接账号并提取存档（仅私聊，开启提取会话）
/zkq 登录方式 <设备> <QQ|微信>          提取流程停在登录方式选择界面时选择（仅私聊）
/zkq 确认提取 <设备>                   村庄截图后确认并提取（仅私聊）
/zkq 取消提取 <设备>                   中止当前这一轮提取（仅私聊）
/zkq 继续提取 <设备> <槽位> [QQ|微信]   提取会话里继续提下一个账号（仅私聊）
/zkq 结束提取 <设备>                   结束提取会话，设备自动重启恢复挂机（仅私聊）
/zkq 帮助             帮助
```

### 扫码提取存档（多账号会话）

`/zkq 扫码提取 手机A 1 QQ` 开启一个提取会话：设备清数据冷启动 → 出二维码（发到对话）→ 你拿**旧设备的那个账号**扫码 → 进村庄截图确认 → 提取到**槽位 1**。之后进入对话门，可继续提下一个号，或结束：

```
第 1 轮：扫码提取 手机A 1 → 扫 → 确认 → 提取到槽位 1
   📋 本轮已结束：槽位 1 提取成功。还需要提取下一个账号吗？
   · /zkq 继续提取 手机A 2 QQ   （提第 2 个号，需换另一台旧设备扫码）
   · /zkq 结束提取 手机A       （结束会话，设备自动重启恢复挂机）
第 2 轮：继续提取 手机A 2 → 换设备扫 → 确认 → 提取到槽位 2
   ...（循环）
```

- 整个会话期间 bot 主流程全程让位（三种模式都会停），会话结束（结束提取 / 3 分钟未回复）后设备**自动杀进程重启**，守护脚本拉起后全新开始挂机配置的账号。
- 每轮失败/取消会回对话门（可换号再来），不结束会话。
- 会话期间再发 `扫码提取` 会被拒，提示用继续/结束。

### 关键词（直接发，不用前缀）

`状态`、`现在跑哪个号`、`当前账号`、`升级还有多久`、`下次升级`、`日志`、`看看日志`、`服务器状态`、`截图`

### AI 对话（自然语言）

- "设备在干什么" → 查状态
- "服务器状态怎么样" → 查服务器
- "把今天的日志发我" / "最近 1 小时日志" / "打包日志" → 按范围打包发送
- "截个图看看" → 截图
- "删掉今天的日志"（仅私聊）→ 删除日志

## 架构

```
设备（手机/云手机，只出站）         服务器（AstrBot）
┌─────────────────────┐   HTTP 快照   ┌────────────────────┐
│ App 脚本              │ ───────────▶ │ 插件 astrbot_plugin_zkq │
│ 快照上传器 / WS 客户端 │              │ 快照表 + WS 服务端     │
│ 日志 / 截图 / 查询解释器 │ ◀─────────── │ QQ 命令 / 关键词 / AI  │
└─────────────────────┘   WS 长连接    └────────────────────┘
```

- **快照通道**：设备每 60s 上报状态摘要，服务器直接读快照即可回答状态类问题
- **WS 长连接**：日志、截图等按需拉取（对话触发才传输），断线自动重连
- **设备零入站**：所有通讯都是设备主动外连，云手机 / NAT 环境无需任何隧道

## 安全说明

- 查询类功能只读，不控制脚本（无暂停/停止/上号等操作）；扫码提取会话（清数据/链接账号/提取存档）与清空日志为破坏性操作，**仅私聊可用**
- 删除日志为破坏性操作，**仅私聊可用**
- 群聊可通过 QQ 白名单限制可查询的用户
- 设备与服务器通讯使用共享密钥：首次启用自动生成随机密钥（日志里可查），QQ 私聊发 `/zkq 重置token` 可重置；App 通过请求头 `X-Zkq-Token` 携带，不经过 URL，避免进入网关日志
- 设备上报的快照内容（QQ 号/备注/事件）只保存在内存，**磁盘不落盘敏感字段**；重启后设备列表保留，状态由设备在一分钟内自动重新上报恢复
- 服务端对快照请求体（1 MiB）、WS 连接数（128 条）设有上限，防止异常/恶意客户端耗尽资源

## 常见问题

**设备列表为空？** 检查 App 端"插件连接地址"是否填写、16841 端口是否放行、插件总开关是否打开。

**查日志提示离线？** 设备 WS 未连接（App 脚本未运行/网络断开），可先 `/zkq ping <设备>` 测试链路。

**群聊发消息没反应？** 群聊普通消息需要 @机器人；只有关键词和 `/zkq` 命令是免 @ 触发。

**改设备备注后旧名字还在？** 新备注会在下次上报时生效并自动清理旧名（快照/连接同步迁移）。
